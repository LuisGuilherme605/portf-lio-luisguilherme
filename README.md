# Portfólio - Luis Guilherme

[Ver online](https://luisguilherme605.github.io/portf-lio-luisguilherme/)

Meu site pessoal. Fiz pra mostrar meus projetos, o que eu sei fazer e como me encontrar. HTML, CSS e JavaScript puro.

## O que tem

- Fundo de estrelas animadas em canvas (pausa quando a aba perde foco)
- Um robô 3D feito com Three.js que segue o cursor
- Cursor customizado com rastro
- Efeito de inclinação 3D nos cards
- Troca de idioma PT/EN, detecta o idioma do navegador
- Animações no scroll, parallax no hero
- Responsivo, respeita `prefers-reduced-motion`

## Tecnologias

HTML5, CSS3, JavaScript, Three.js, Google Fonts (Sora + Space Mono).

## Estrutura

```
index.html       página principal
style.css        estilos
features.css     toggle de idioma e botão de WhatsApp
script.js        estrelas, cursor, parallax, menu, tilt
features.js      lógica PT/EN
robot3d.js       robô 3D
```

## Como rodar

```bash
git clone https://github.com/LuisGuilherme605/portf-lio-luisguilherme.git
cd portf-lio-luisguilherme
```
